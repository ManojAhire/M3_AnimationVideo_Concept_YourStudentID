M3 ANIMATION VIDEO STARTER PACK

TOPIC
Derivative as rate of change, using f(x) = x^2 at x = 1.

FILES
- M3_Derivative_Rate_of_Change.pptx: editable 16:9 slide project. This is the editable project/source file accepted by the assignment brief for PowerPoint/Keynote.
- Storyboard.pdf: six-scene storyboard required by the brief.
- Narration_Script.txt: slide-by-slide voice-over script.

BEFORE YOU RECORD
1. Open the PPTX in Microsoft PowerPoint. Replace YOUR NAME and YOUR ID on slide 1.
2. Read the narration script once. You do not need to memorise it.
3. On slides 5-7, select Transitions > Morph if your PowerPoint version supports it. (Slide 4 is the first secant position.) Otherwise use Fade. Preview the transitions to confirm the secant line visibly changes as Q moves towards P.
4. Check the equations: the secant slope is (a^2 - 1)/(a - 1) = a + 1 for a != 1; as a approaches 1, the slope approaches 2; the tangent line is y = 2x - 1.

RECORD ON POWERPOINT (DESKTOP)
1. Open the PPTX. Choose Slide Show > Record Slide Show (or Record).
2. Start from the beginning. Read the matching part of Narration_Script.txt for each slide.
3. Advance the slides as you speak. Pause briefly on the moving graph slides so the change can be seen.
4. At the end, stop recording and save the presentation.
5. On PowerPoint for Mac, choose File > Export, select MP4, choose Full HD (1080p), and tick Use Recorded Timings and Narrations. On Windows, use File > Export > Create a Video and choose Full HD (1080p).
6. Play the exported MP4 once from beginning to end. Confirm audio is clear, the whole slide is visible, and the duration is below 7 minutes.
